# Paulines' Kitchen Demo
A web-based ordering management system developed for Paulines' Kitchen to improve the ordering process and provide customers with a more convenient way to place orders online. This project was built as a demonstration system and showcases basic e-commerce functionality, including online payments and email notifications.

## Live Demo
https://paulineskitchen.infinityfree.me

## Project Overview
The system was completed within a 13-day development sprint and deployed using InfinityFree for demonstration purposes. AI tools were used to assist with debugging, learning unfamiliar concepts, and improving code during development.

## Features
- Customer registration and login
- Browse food menu by category
- Shopping cart
- Place customer orders
- Order management
- Secure online payment using PayMongo
- Email notifications using PHPMailer
- Responsive user interface
- Admin dashboard for managing products and orders
